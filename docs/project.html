How it works

Read. Launch. Reconsider.

Read the field

Check each arrow’s direction, the current polarity, walls, and the magnetic zones that can bend its path.

Choose an arrow

Launch one arrow and let the board resolve the full route. Failed actions leave the board unchanged, so you can rethink safely.

Clear the board

Use what changed—including any polarity flip—to find the next move. Remove every arrow to complete the puzzle.
